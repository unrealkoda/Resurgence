# DayZ Resurgence Lite — Console Server Package

This package contains server configuration files for console 
DayZ servers running a Resurgence tuned experience.

## What Is Included

- Survival stat tuning — hunger, thirst, blood, infection
- Loot economy overhaul — balanced and intentional
- Zombie tuning — more dangerous and numerous
- Animal behaviour — passive animals tuned for hunting
- Weather and temperature — harsher survival conditions
- Medical system tuning — infection and disease more serious
- Globals tuning — cleanup times, logout penalties

## What Is Not Available On Console

The following features from DayZ Resurgence PC require 
mod scripting unavailable on console:

- Karma and outfit system
- Energy and sleep mechanics
- Advanced cooking and recipes
- Trader NPC system
- Vehicle overhaul
- Dynamic world events
- Custom HUD elements

For the full DayZ Resurgence experience please visit our 
PC Workshop page.

## Installation

1. Copy the ResurgenceLite.chernarusplus folder to your 
   server mpmissions directory
2. Update your serverDZ.cfg template line to:
   template="resurgenceLite.chernarusplus"
3. Restart your server
